# Thames Freight Rail Database

## Project Overview
This project was developed as part of the MSc Data Science programme at Kingston University London.

It demonstrates relational database design and implementation using Oracle SQL and Oracle APEX.

## Key Features
- Designed an Entity Relationship Diagram (ERD).
- Implemented 15 relational database tables.
- Defined primary keys, foreign keys and composite keys.
- Resolved many-to-many relationships using associative tables.
- Executed SQL queries involving joins, filtering and aggregation.
- Inserted sample records to validate database relationships.

## Technologies Used
- Oracle SQL
- Oracle APEX
- Relational Database Design
- Entity Relationship Modelling

## Project Purpose
To design a relational database for managing freight railway operations, including locomotives, wagons, drivers, routes and consignments.
